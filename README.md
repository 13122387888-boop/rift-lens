# 对局透镜 · 海斗玩家卡

海克斯大乱斗战绩查询、趣味玩家画像与高清 PNG 玩家卡。默认最近 10 场，保留 20/30 场和其他模式；详细统计与复盘可以展开查看。

## 打开网站

https://13122387888-boop.github.io/rift-lens/

GitHub Pages 静态站点，不需要登录 GitHub 或 ChatGPT。

## 本地开发与发布

需要 Node.js 22.13 或更新版本。

- npm ci
- npm run dev
- npm test
- npm run build

构建输出 docs/。GitHub Pages 发布源为 main 分支的 /docs 文件夹；修改源码后重新构建并提交 docs/ 即可发布。docs/.nojekyll 由构建后脚本生成。

## 数据与权限

浏览器只访问 https://a.lzyumi.top/lzyumi/lol/info 下的三个已观察到的公开 GET 接口。2026-09-04 已确认正常响应提供 Access-Control-Allow-Origin: *。不附加 Cookie、不收集登录凭据、不绕过验证或权限控制。源站仍可能改变接口或跨域策略，届时应显示错误而不能保证查询继续可用。Riot ID 与大区会发送到这个数据源。

时间参数使用源站前端已公开的 MD5 格式，由浏览器生成；它不含私钥或账户凭据。MD5 仅为源站兼容格式，不用于密码或安全认证设计。

当前没有自己的查询后端，不依赖先前的 ChatGPT Sites 私人地址。分析、截图、PNG 生成和有容量上限的缓存都在当前浏览器完成。缓存查询 60 秒、成功详情最多 6 小时，刷新或关闭页面会清空。

海斗从源站最近 30 场全部对局中筛选，最多展示选择的场数，不冒充完整历史。日期没有年份时不补造年份。默认真实样本采集于 2026-09-03，查询后替换为来源结果。

趣味称号有公开规则且仅描述本次样本，不是官方段位、个人 MMR 或全服排名。ELO 对照来源见 reference/elo-reference.md。缺失值保留为 —，不当作 0。

战报在浏览器本地生成，支持保存/复制 PNG 和隐藏玩家名称。复制图片取决于浏览器 Clipboard API；不可用时可以保存图片。

## 玩家画像

英雄定位采用 Riot Data Dragon 16.17.1 的 champion.json tags，版本、来源和采集时间保存在 lib/champion-roles.json。战士、坦克、射手、法师、刺客、辅助六种定位按本次海斗出场加权，双定位各计半场。未知英雄不记作任何定位；至少识别 5 场且覆盖 80% 对局才生成类型。

占比第一的定位达到 30%、领先第二至少 10 个百分点时归为单一类型；否则前两类合计至少 60%、第二至少 20% 时为双修，其余为多面型。显示占比使用最大余数法取整数，合计 100%。这仅反映本次英雄选择，随机选人会影响结果，不代表操作水平或真实人格。

趣味标签提供可展开的依据，不补造缺失指标，不混入其他模式。玩家卡包含类型、英雄口味、常出场英雄及最多三个标签；网页可展示最多三个。已保留隐藏姓名、PNG 保存和图片复制功能。测试覆盖双定位、混合定位、未知英雄、少量/不完整样本、模式隔离、连胜中断和图片隐私。

## 手机与小伙伴

手机端采用单列玩家卡，图片下面直接保存或复制。已检查 320、375、390、768、1440 像素宽度，主要操作按钮至少 44 像素高。高光头像与列表头像统一使用随站点发布的 Riot Data Dragon 16.17.1 图片，来源见 public/champions/SOURCE.json；不依赖截图时跨域加载图片。

开黑小伙伴模块基于本次海斗战绩中至少两次同队的玩家，提供共同场次、胜负和可展开的对局记录。来源没有可验证的组队 ID，因此界面明确说明同队不等于组队；不把敌方、自己或仅出现一次的玩家算成小伙伴。仅完整的 10 人、双方各 5 人且身份唯一的名单参与统计。姓名可以隐藏，来源账户标识在标准化时转换为稳定摘要，不在页面展示原始标识。示例同队名单补采时间见每场 teammatesFetchedAt。
